# 🔐 Gerador de Senhas Seguras

Um gerador de senhas seguras desenvolvido em Python como projeto
de aprendizado e prática de programação.

## 📌 Sobre o projeto

Este projeto permite gerar senhas personalizadas definindo:

- O tamanho da senha
- Letras maiúsculas
- Letras minúsculas
- Números
- Símbolos

A geração dos caracteres utiliza o módulo `secrets` do Python.
